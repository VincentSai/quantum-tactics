# 🎮 Quantum Tactics: HexOutpost (量子先锋：前哨争夺战)
## 游戏产品需求说明书 (Game Product Requirement Document - PRD)

### 1. 项目背景与目标
- **悬赏标的**：TaskMarket `TSK-V6J8MSSD` (10.00 USDC)
- **定位**：一款轻量、极具策略深度、单局 3~8 分钟的回合制多人（2-4 人）策略棋盘对战游戏。
- **双端核心体验**：
  1. **人类玩家**：零门槛 Web 浏览器即点即玩，无安装、无登录、支持房间码联机与一键 Bot 补位；
  2. **AI Agent**：标准化轻量 HTTP/JSON API，提供清晰的游戏状态轮询与合法行动提交，内置智能启发式 Sample Bot。
- **评测核心考量 (Judging Bar)**：趣味性 (Fun)、Agent API 易用性、打磨度与视觉手感 (Polish)、跨端稳定性。

---

### 2. 核心玩法机制设计 (Game Mechanics)

#### 2.1 规则 (One-Paragraph Rule)
> 在 5x5 的量子能量晶格棋盘上，2 到 4 名指挥官（人类或 AI Agent）各自统领核心基地与战术机甲。对局以回合制进行，每回合拥有 2 点行动力（AP），可用于执行：**机动移动**（Movement）、**部署防护力场**（Deploy Shield，吸收 1 点致命伤害）、或**超载冲击**（Overload Strike，攻击相邻或对角敌方单位）。棋盘中央设为“量子主前哨”（Central Outpost，坐标 [2,2]），率先累积控制主前哨 3 回合，或消灭所有敌方指挥官者立即获得胜利。克制闭环与紧凑地形保证绝无单一必胜策略（No Dominant Strategy），每回合决策充满博弈张力！

#### 2.2 棋盘与数值设定
- **棋盘规模**：5x5 网格矩阵 `[0..4, 0..4]`；
- **玩家人数**：2~4 人（红、蓝、绿、黄四方出生于四个角落 `[0,0]`, `[4,4]`, `[0,4]`, `[4,0]`）；
- **基础属性**：
  - 每位指挥官初始 HP = 3；
  - 每回合 Action Points (AP) = 2；
  - 护盾上限 = 1（开启后持续到被攻击打破或下一个自身回合开始）；
- **行动类型与 AP 消耗**：
  - `MOVE` (消耗 1 AP)：移动到上下左右相邻空格（如果该格有能量晶体，立即获得 +1 临时 AP）；
  - `ATTACK` (消耗 1 AP)：对距离为 1 的敌方单位发起冲击，敌方若有护盾则抵消护盾，若无护盾则扣除 1 HP；
  - `SHIELD` (消耗 1 AP)：开启或刷新自身防护罩（吸收 1 次伤害）；
  - `PASS` (消耗剩余所有 AP)：放弃剩余行动，结束当前回合；
- **胜负判定条件 (Win Conditions)**：
  1. **主前哨统治胜利 (Domination)**：在中央据点 `[2,2]` 上累计控制达到 3 个回合计数点；
  2. **歼灭胜利 (Elimination)**：将对手指挥官生命值减至 0，最后存活的一方获胜；
  3. **超时终局判决**：若超过 40 回合，按据点控制点数 > 剩余血量 > 造成伤害量决出胜负。

### 3. 系统功能架构
1. **对战大厅与房间系统**：
   - 创建新房间（生成 4 位简明房间码，例如 `QT88`）；
   - 加入房间（通过房间码快速入席）；
   - 一键“Add AI Bot”补齐空缺座位，支持“人类 vs 电脑”、“人类 vs 人类”、“电脑 vs 电脑 (Spectate Mode)”；
2. **实时对战与事件日志**：
   - 棋盘高亮显示当前玩家位置、合法移动范围、可攻击目标；
   - 战术面板显示各玩家当前生命值、护盾状态、前哨占领进度、行动力剩余；
   - 实时滚动的 Match Log 记录每一次战术操作；
3. **复盘回放 (Match Replay)**：
   - 游戏结束后自动生成完整对局快照列表，支持单步向前/向后回放对局全过程；
4. **Agent HTTP API**：
   - 标准 RESTful 端点，自解释的 JSON 响应，包含 `valid_moves` 列表，AI 编写极速上手。
